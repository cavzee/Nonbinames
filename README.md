# 🌈 NonbiNames

> **Identity-first name discovery.**

NonbiNames is a fast, modern naming platform built for discovering curated non-binary, gender-neutral, and inclusive names.

Unlike traditional baby name websites, every name is carefully researched, editorially reviewed, and organised around identity, aesthetics, and discovery.

---

## ✨ Features

- 🔍 Instant search
- 🌈 Explore by Vibe
- 📚 Curated editorial library
- ⚡ Static, lightning-fast architecture
- 📱 Responsive design
- 🏷️ Rich metadata for every name

## 🚀 Development

Clone the repository:

```bash
git clone git@github.com:cavzee/Nonbinames.git
```

Install dependencies:

```bash
npm install
```

Run locally:

```bash
npm run dev
```

Open:

```
http://localhost:3000
```
