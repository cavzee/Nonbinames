# NonbiNames Editorial Style Guide

> Every name on NonbiNames is intentionally curated.

This document defines the standards used when adding new names to the dataset.

---

# Our Philosophy

NonbiNames is not trying to become the biggest naming website.

Our goal is to become the most trusted, thoughtfully curated, and identity-first naming platform.

Every name should earn its place.

Quality always comes before quantity.

---

# Editorial Principles

Every name must be:

- Verified from reliable sources
- Genuinely used, historically attested, or culturally recognised
- Suitable for discovery by our audience
- Tagged consistently
- Written using the same formatting rules

When in doubt, research first.

---

# Research Workflow

Every new name follows this process:

1. Candidate name
2. Research and verification
3. Editorial review
4. JSON entry
5. Git commit

No name should skip verification.

---

# Trusted Sources

Examples include:

- Behind the Name
- Wiktionary
- Government baby name statistics
- Historical and linguistic references
- Academic or reputable etymology resources

Multiple sources should be used whenever possible.

---

# Required Fields

Every name must include:

- id
- slug
- name
- meaning
- pronunciation
- origin
- collections
- themes
- tags
- similar
- featured

No incomplete entries.

---

# Collections

A name may belong to multiple collections.

Examples:

- Modern
- Nature
- Celestial
- Mythic
- Classic
- Traditional Unisex
- Rare
- Bold
- Soft
- Ocean
- Autumn
- Earthy
- Futuristic

Collections describe how users discover names.

---

# Themes

Themes describe factual associations.

Examples:

- Nature
- Space
- Water
- Forest
- Sky
- Mythology
- Colour

Themes should remain objective.

---

# Tags

Tags provide additional context.

Examples:

- Floral
- Botanical
- Short
- Minimal
- Vintage
- Literary
- Gender Neutral

Keep tags concise.

---

# Similar Names

Similar names should genuinely feel related.

Relationships may be based on:

- Sound
- Style
- Meaning
- Shared collection
- Shared origin

Avoid random suggestions.

---

# Meanings

Meanings should be:

- Short
- Accurate
- Easy to understand

Avoid lengthy descriptions.

---

# Pronunciation

Use a simple pronunciation guide.

Example:

AS-ter

rather than complex phonetic notation.

---

# Origins

Use the primary linguistic or cultural origin.

Examples:

- Greek
- Latin
- English
- Japanese
- Welsh

Keep terminology consistent.

---

# Featured Names

Only mark names as featured if they represent the quality and diversity of the collection.

Not every name should be featured.

---

# Data Standards

- Use consistent capitalisation.
- Keep JSON formatting clean.
- Do not duplicate names.
- Every slug must be unique.
- Every id must be unique.

---

# Long-Term Goal

Build the world's most trusted, thoughtfully curated identity-first naming dataset.

Every new entry should make the collection stronger.
